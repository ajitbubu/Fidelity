# Portfolio Intelligence Dashboard

Next.js + React + Tailwind dashboard for uploading brokerage CSV snapshots, evaluating portfolio performance, and planning toward a `$450,000` year-end target.

## Features

- CSV upload + local persistence
- Portfolio summary cards
- Holdings table with rule-based recommendations
- Daily pre-market plan panel (mock macro/news data)
- Target progress board + scenario calculator
- Alerts board
- Recharts visualizations (allocation, sector, gain/loss, target progress, concentration)

## Pages

- `/dashboard`
- `/upload`
- `/recommendations`
- `/alerts`
- `/settings`

## Run

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
